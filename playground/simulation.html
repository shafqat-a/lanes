Steering function

Changing work restores the example. Source or count changes reset the field. Each agent packs x/y positions into the lowest 20 bits and a seed into the upper 12. Positions wrap at 1,024; arithmetic wraps as i32. Agents share the function and do not interact.

Timing & verification

With a GPU, every step runs both paths and checks every output before drawing. Playback includes that verification, so its frame rate is not a backend benchmark. Native compute runs in one worker; its timer excludes messaging. GPU total includes allocation, upload, dispatch, readback, and cleanup. The first call after editing includes pipeline compilation and is labeled cold. Canvas time measures pixel preparation and the draw call, not screen presentation. Timings are individual samples, not stable benchmark medians.

For edited code, native JavaScript is generated from validated integer IR inside a worker. It is a native execution comparison, not an independently authored algorithm. Both paths are also checked against the CPU interpreter on 64 sampled inputs after each edit. No source is uploaded.

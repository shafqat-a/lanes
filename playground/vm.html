TOWARD ECMASCRIPT 2025 ON THE GPU

JavaScript numbers.
GPU execution.

An experimental bytecode VM with software double-precision arithmetic. CPU compilation, GPU instruction execution, and CPU execution only when WebGPU is unavailable.

Experimental ES2025 runtime. Supports numeric primitives, basic UTF-16 string operations, nested functions, recursion, closures, throw/catch/finally, and garbage collection for strings and lexical environments. General objects, arrays, and async remain unimplemented. Unsupported features produce errors on either backend.

Function

Initializing

Each GPU dispatch executes a bounded number of instructions, preserving VM state for the next dispatch. Cancellation takes effect between dispatches. Device loss stops execution; it never replays work on CPU.

The conformance runner compares the supported subset with native JavaScript using Object.is, including NaN and signed zero. It covers seeded binary64 bit patterns, numeric edge cases, recursion, closures, exceptions, strings, and collection of unreachable heap values. These targeted tests do not establish full ECMAScript conformance.

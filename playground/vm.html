TOWARD ECMASCRIPT 2025 ON THE GPU

JavaScript numbers.
GPU execution.

An experimental bytecode VM with software double-precision arithmetic. CPU compilation, GPU instruction execution, and CPU execution only when WebGPU is unavailable.

Foundation, not full JavaScript yet. Supports number, boolean, null, undefined, arithmetic (+ − × ÷), bitwise operations, comparisons, local variables, if, for, while, and return. Strings, objects, arrays, function calls, exceptions, and async are not implemented. Unsupported features produce errors on either backend.

Function

Initializing

Each GPU dispatch executes a bounded number of instructions, preserving VM state for the next dispatch. Cancellation takes effect between dispatches. Device loss stops execution; it never replays work on CPU.

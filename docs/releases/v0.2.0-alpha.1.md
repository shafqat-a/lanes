# Lanes v0.2.0-alpha.1 — experimental JavaScript execution on WebGPU

This prerelease snapshots the QuickJS compiler + direct WGSL runtime, verified on Apple M1 / Safari 26.4. It is **not full ECMAScript 2025 support or a production-ready 1.0**. CPU parsing/compilation is allowed; supported guest programs execute on GPU. The host schedules dispatches and explicit services.

## What is included

- Direct GPU bytecode execution with software binary64 arithmetic, objects, closures, exceptions, garbage collection, and resumable execution.
- Implemented subsets of classes, Symbols, BigInt, collections, generators, promises, async functions, and standard-library methods. These families are not certified complete.
- Real Script compilation with a fresh realm per lane, lexical bindings, global declarations, and Script completion values.
- Array.flat, flatMap, and splice, including focused species, sparse-array, coercion, GC, and resumption checks.
- A compile-only dynamic Function service; guest Function calls are still unsupported.
- Existing numeric i32 JIT and older VM APIs remain available separately.

## Not yet implemented or incomplete

1. Persistent realms: globals and lexical environments retained across separate Script executions; dynamic global lexical lookup.
2. Modules: linking, live bindings, cycles, namespace objects, import.meta, dynamic import, and top-level await.
3. Dynamic guest code: direct/indirect eval, executable Function constructors, dynamic generator/async constructors. The host compiler service lacks live-code linking and GPU request/response integration; source transport also has NUL/unpaired-surrogate restrictions.
4. Remaining language/constructor forms: class and method gaps, alternate intrinsic/derived newTarget, and built-in subclassing, including collection and Promise gaps.
5. Complete built-in object semantics: intrinsic property descriptors, own-key ordering, extensibility, prototype relationships, and exotic-object behavior across all required objects.
6. Proxy and Proxy.revocable, including traps and invariants.
7. RegExp and complete String/Symbol matching, search, replace, and split protocols.
8. Date, including time and timezone host-service contracts.
9. ArrayBuffer, DataView, and complete ES2025 typed arrays, including Float16/BigInt variants and applicable resize/detach/transfer behavior.
10. SharedArrayBuffer, Atomics, JavaScript agents, and shared-memory semantics.
11. WeakMap, WeakSet, WeakRef, and FinalizationRegistry integrated with GC.
12. Remaining built-ins, including String normalization, nondecimal Number formatting, Math.random, URI globals, and outstanding protocol/constructor behavior. This list is not an exhaustive per-method compatibility table.
13. Complete ES2025 Iterator helpers and synchronous/asynchronous iterator protocol coverage.
14. Complete Promise/async behavior, particularly subclass/newTarget cases and host-request/job-queue integration.
15. Practical configurable/growable storage. Current per-invocation limits include 2,048 heap nodes, 256 UTF-16 units per string, 32 frames, 256 operand slots, 16 declared parameters, 64 locals, and 64 captures per function. Not all heap nodes can remain live simultaneously.
16. Public object/function/Symbol value transfer, identity and cycle preservation, and lifetime management; public transfer currently supports primitives.
17. Whole-job CPU fallback for the new runtime when WebGPU is unavailable. Unsupported features, GPU errors, and device loss never trigger CPU replay.
18. Full applicable ES2025 Test262 execution: Script/module/async/realm/agent harness coverage and resolution of unsupported, failing, and resource-limited cases. Inventory and expected rejection counts are not conformance passes.
19. M1/Safari release qualification: sustained workloads, long-lived realms, stress, memory/device-loss handling, and startup/throughput targets. Shader compilation is still expensive.
20. Stable full-engine public API/types, packaging, reproducible release gates, and complete compatibility documentation.

NVIDIA and other platform qualification are deferred. This runtime is not a security sandbox. DOM, networking, timers, and Intl integration are outside the support claim for this release.

## Verification and limits of the evidence

The released runtime source matches 531 source entries in the frozen new-wave candidate hash record.

- Latest candidate, M1/Safari: main regression **1,209 programs / 10,881 values / 238 negative checks**, with resumption checks passing.
- Script entry: **36 programs / 144 values / 8 rejection checks**, with resumption and GC coverage.
- Array additions: **49 programs / 106 values**, plus resource and GC coverage; 600 host differential cases.
- Dynamic compilation service: **13 host tests**; this does not establish GPU Function support.
- Single observed shader compilation sample: 10.604 s + 4.542 s + 23.385 s (about 38.5 s total); not a general benchmark or speedup claim.

The earlier candidate passed 788 standard-library programs and 569 Promise programs. Those complete aggregates were **not rerun on the latest candidate** and are not presented as its passes. Exact reports and source hashes are included under experiments/bootstrap/evidence; start with quickjs-1_0-parallel-wave1.json. No full-language conformance percentage is claimed.

Release packaging checks: 49 CPU tests passed, TypeScript checks passed, and the package build/pack completed. All 148 generated candidate hashes were verified before packaging the browser asset. Existing whitespace in frozen sources, captured logs, and upstream licenses was preserved to retain provenance.

## Downloads and usage

- **lanes-webgpu-0.2.0-alpha.1.tgz**: npm-format package for the existing numeric JIT and older experimental VM. It does **not** export the new QuickJS/WGSL engine. Install locally with `npm install ./lanes-webgpu-0.2.0-alpha.1.tgz`.
- **lanes-quickjs-browser-0.2.0-alpha.1.tar.gz**: prebuilt experimental browser compiler, runtime, and test pages from the M1-verified candidate. Extract into an empty directory, run `python3 -m http.server 4178 --bind 127.0.0.1`, and open `http://localhost:4178/` in Safari on M1. Focused pages include script-entry.html and array-completion.html. These are test/demo pages, not a stable packaged API.
- GitHub source archives include compiler/runtime sources, vendored dependencies and licenses, tests, and evidence. Build instructions are in experiments/quickjs-runtime/README.md; compiler builds require Emscripten 4.0.22.
- **SHA256SUMS.txt** records download checksums.

This is a GitHub prerelease. No npm registry publication is implied.
